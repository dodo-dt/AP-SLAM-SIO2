# 📦 Lot 3 : Développement PHP et Sessions

## 📖 Introduction du Lot
Ce troisième lot est le cœur du développement web backend. L'objectif est de donner vie à la "coquille vide" du Lot 2 en connectant les pages HTML à la base de données MySQL grâce au langage PHP.

## 🎯 Objectifs du Lot
- Établir une connexion sécurisée à la base de données via PDO.
- Développer un système d'authentification robuste (inscription, connexion, déconnexion) en gérant l'état de l'utilisateur grâce aux Sessions (`$_SESSION`).
- Remplacer les données codées en dur dans le HTML par un affichage dynamique du catalogue des produits extraits de la base de données.

## ✅ Livrables et Rendus

| Livrable Attendu (Cahier des charges) | Fichiers PHP et Scripts concernés | Statut |
| :--- | :--- | :---: |
| **Page d'accueil** | `index.php` (Page par défaut, dynamisée). | ✅ |
| **Page d'inscription** | `inscription.php` (Création d'un compte client en BDD). | ✅ |
