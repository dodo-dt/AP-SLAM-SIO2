# 📦 Lot 2 : Front-End Statique et Base de Données

## 📖 Introduction du Lot
Cette deuxième étape marque la transition de la théorie à la pratique. Il s'agit de construire la "coquille vide" de l'application : l'intégration visuelle sur le navigateur et la création physique des tables sur le serveur de base de données.

## 🎯 Objectifs du Lot
- Transformer les maquettes IHM du Lot 1 en véritables pages web fonctionnelles visuellement (HTML/CSS), mais sans logique dynamique (sans PHP).
- Rédiger les scripts SQL permettant de générer la structure exacte de la base de données à partir du MLD.
- Mettre en place les outils de collaboration et de gestion de projet (Trello, Github).
