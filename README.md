# Projet AppResto - Lot 2 (Conception BDD et Site Statique)

## Introduction
Le projet **AppResto** est une application web developpee dans le cadre du module **Ateliers de Professionnalisation (AP.SLAM)** en **BTS SIO 2eme annee** a l'Institut LIMAYRAC, durant l'annee scolaire 2025/2026. [cite: 1, 93]

Ce depot est exclusivement dedie aux livrables du **Lot 2**.

---

## Description du Besoin (Lot 2)
L'objectif de ce lot est la mise en place des fondations techniques et visuelles de l'application :
* Creation de la structure de la base de donnees (MLD et MPD). [cite: 13, 14]
* Developpement d'une interface utilisateur statique fonctionnelle en HTML/CSS. [cite: 16, 21]

---

## Livrables du Lot 2

### 1. Base de Donnees
* **MLD (Modele Logique des Donnees)** : Fourni au format graphique (PNG/JPEG) et au format textuel (TXT). [cite: 19, 35, 36]
* **MPD (Modele Physique des Donnees)** : Script SQL incluant la creation de la base de donnees (`CREATE DATABASE`). [cite: 19, 37]
* **Jeu de donnees d'essai** : Fichier SQL contenant les requetes `INSERT` pour tester l'application. [cite: 38]

### 2. Interface Statique (HTML/CSS)
Le dossier `/Appresto` contient le site statique avec les fonctionnalites suivantes (sans PHP) : [cite: 22, 38]
* **Authentification** : Pages d'inscription, de connexion et de deconnexion. [cite: 29]
* **Catalogue** : Affichage de la liste des produits et selection des quantites. [cite: 30]
* **Commande** : Choix du mode de consommation (sur place ou a emporter). [cite: 31]
* **Calculs & Paiement** : Calcul du total TTC et interface de paiement fictive par carte bancaire. [cite: 32, 33]

### 3. Gestion de projet
* **Trello** : Le lotissement est detaille sur Trello avec affectation precise des taches pour chaque membre du groupe. [cite: 20, 38]
