# Projet AppResto - Lot 1 (Conception)

## Introduction
Le projet **AppResto** est une application web developpee dans le cadre du module **Ateliers de Professionnalisation (AP.SLAM)** en **BTS SIO 2eme annee** a l'Institut LIMAYRAC, durant l'annee scolaire 2025/2026.

Ce depot presente les documents de conception initiaux realises pour le **Lot 1**.

---

## Description Globale du Besoin
L'objectif du projet est de proposer une application web permettant a un client de s'inscrire, de se connecter et de commander des repas aupres d'un restaurateur.
Le processus integre la gestion des statuts de commande (initialisee, en attente, en preparation, prete, servie, etc.) et le calcul des totaux incluant une TVA variable (10% sur place, 5,5% a emporter).

---

## Livrables du Lot 1
Ce lot definit l'architecture theorique et visuelle de l'application. Le dossier `doc/` contient les documents suivants au format PDF :

* **Diagramme des Cas d'Utilisation** (`Diagramme des cas d_utilisations.drawio.pdf`) : Definit les interactions possibles des utilisateurs avec le systeme.
* **Diagramme d'activites** (`Diagramme d_activité.drawio.pdf`) : Modelise le processus de commande.
* **Modele Conceptuel des Donnees** (`MCD.APPRESTO.pdf`) : Representation logique de la structure de la base de donnees.
* **Modele Logique des Donnees** (`MLD.APPRESTO.pdf`) : Traduction du MCD sous forme de tables relationnelles.
* **Sitemap / IHM** (`sitemap restoapp.drawio.pdf`) : Plan du site illustrant l'enchainement des pages.
